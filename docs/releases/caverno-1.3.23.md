# Caverno v1.3.23

> Release date: 2026-09-07

## Summary

This maintenance release updates the Caverno marketing version and platform
build number for the iOS and macOS distribution cycle.

## Changes

### Maintenance

- **Release metadata** — Advance the marketing version from `1.3.22` to
  `1.3.23` and the build number from `34` to `35`.
- **iOS dependency lock** — Refresh the CocoaPods lockfile for the existing
  Firebase Crashlytics integration used by the release build.

## Testing

- No application code changes were introduced after `1.3.22+34`; this release
  contains release metadata and the iOS dependency lock refresh only.

## Version

- `1.3.23+35`

## Notes

Git history contains no commits after `1.3.22+34`. The previous release's
functional changes remain documented in
[`docs/releases/caverno-1.3.22.md`](caverno-1.3.22.md).
