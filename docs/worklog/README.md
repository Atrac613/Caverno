# Worklog

Dated investigations, findings, measurements, decisions, inventories and
release records. These are history: each one describes the code as it was
when written, and none is kept current. For how things work now, start from
[`../README.md`](../README.md).

Add a document here when it records something that happened (a session
analysis, a measurement, a decision and its evidence). Put the date in the
file name, e.g. `topic_YYYY-MM-DD.md`.
